Melodee in the browser

Melodee @VERSION@'s UI and sound, as WebAssembly, on a drawn FM-1: the same code the FM-1 runs. Mouse, touch, or the computer keyboard (the letters on the keys). Nothing is saved; there is no USB. Install it on your FM-1.
